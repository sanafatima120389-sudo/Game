FREE FIRE CODING - WEBASSEMBLY PROJECT

इस project में आपका original Pygame code main.py के रूप में रखा गया है।

WEB BUILD:
Pygbag का इस्तेमाल करके Pygame game को browser/WebAssembly build में package किया जा सकता है।

सामान्य command:
    python -m pygbag main.py

अगर आपका Pygbag version folder-based build मांगता है, तो उसके अनुसार project folder को input दें।

IMPORTANT:
- main.py = आपका original game code
- यह ZIP खुद compiled .wasm file नहीं है।
- WebAssembly build करने के लिए Pygbag toolchain चाहिए।
- Android APK के लिए पहले web build बनाना होगा, फिर उसे WebView/Android wrapper में package किया जा सकता है।
